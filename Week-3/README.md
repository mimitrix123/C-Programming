# C Programming - Week 3

## Pointers & Strings

Based on the Week 3 assignment sheet:
- Pointer Basics and Arithmetic
- Strings and String Functions
- Dynamic Memory Allocation (`malloc`, `free`)

## Assignments

1. `week3/assignment1_reverse_string.c` - Reverse a string using pointers.
2. `week3/assignment2_vowels_consonants.c` - Count vowels and consonants.
3. `week3/assignment3_swap_pointers.c` - Swap two numbers using pointers.
4. `week3/assignment4_malloc_array.c` - Allocate memory for an array using `malloc` and release it with `free`.

## Mini Project

`week3/mini_project_word_counter.c` - Word Counter Program using pointers and strings.

## Compile in VS Code terminal

From the repository root:

```bash
gcc week3/assignment1_reverse_string.c -o week3/assignment1_reverse_string.exe
gcc week3/assignment2_vowels_consonants.c -o week3/assignment2_vowels_consonants.exe
gcc week3/assignment3_swap_pointers.c -o week3/assignment3_swap_pointers.exe
gcc week3/assignment4_malloc_array.c -o week3/assignment4_malloc_array.exe
gcc week3/mini_project_word_counter.c -o week3/mini_project_word_counter.exe
```

Run on Windows:

```bash
.\week3\assignment1_reverse_string.exe
.\week3\assignment2_vowels_consonants.exe
.\week3\assignment3_swap_pointers.exe
.\week3\assignment4_malloc_array.exe
.\week3\mini_project_word_counter.exe
```
